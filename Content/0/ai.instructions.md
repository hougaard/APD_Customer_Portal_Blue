# Customer Portal

Create a Customer Portal for CRONUS (Selling furniture) with the following content:

* View Statement
* Download invoices PDF (and credit memos) (Create a report action for invoice report 1306 and credit memo report 1307)
* Order new products (by creating Sales Quotes)
    * Create a Script action that creates a new sales quote and an edit page with an "Add Item" function (script)
* See coming shipments

Use Bulma for CSS styling, dark style, make the color scheme edgy and dark'ish, keep the theme with a blue'ish color scheme. Restyle the current login action to match the portal. Make sure all text is with a proper contrast, easy to read.

Use fields from Company Information table for phone numbers, emails, company name etc...

When done, ask the user to define missing security filters

Please ignore the WELCOME action and template
